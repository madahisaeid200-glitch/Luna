# LUNA Asset Registry

Every important creative asset must have one record here. Never rely on a filename alone or on an image remembered from a chat.

## Required fields
- Asset ID: stable identifier or Library file ID.
- Exact filename and storage location.
- Character(s): LUNA / LEO / couple / other.
- Created date and revision lineage.
- Status: APPROVED / REJECTED / EXPERIMENTAL / UNVERIFIED / SUPERSEDED.
- Approval evidence: exact user statement and date, if approved.
- Intended use and known defects/limitations.
